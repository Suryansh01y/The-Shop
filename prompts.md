# AI Usage — ShopZone

AI tools were used during the development of ShopZone mainly for **learning, understanding concepts, debugging, and improving code**.

### Prompts Used

1. **Project Understanding**

   > Explain the requirements of this React e-commerce project in simple terms.

2. **React Concepts**

   > Explain useState, useEffect, props, components, and React Router in simple Hinglish with examples.

3. **API Integration**

   > Explain how to fetch product data from an API in React and display it on the page.

4. **Cart Functionality**

   > Explain the logic for adding, removing, and updating products in a React shopping cart.

5. **Debugging**

   > Explain this React/JavaScript error, why it is happening, and how I can fix it step by step.

6. **CSS & Responsive Design**

   > Explain how to fix this CSS layout issue and make the component responsive.
